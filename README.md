# Hyperlock - three.js-based aim trainer

A small browser-based aim trainer built with three.js to practice flicks and precision clicking in 3D space.  

## Features

- 3D scene rendered with three.js for an FPS‑style aim training feel.  
- Clickable targets spawning in front of the camera.  
- Score and basic performance feedback (hits vs. misses / time).  
- Aiming scenarios created via Lua scripting (using `wasmoon`).
